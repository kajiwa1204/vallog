# Vallog 事業計画書

## 1. 事業概要

**プロダクト名**  
Vallog

**事業コンセプト**  
チーム開発における個人の仕事と貢献を、客観的なデータとして記録し、組織内外で活用できる「実績パスポート」を提供する。

Vallogは、GitHubを中心とした開発データを取得し、メンバーごとの担当業務、作業量、レビュー、課題解決、プロジェクトへの貢献を可視化するサービスである。

日常的には、チーム内の振り返り、報酬分配、人事評価、プロジェクト管理に利用される。

蓄積されたデータは、本人の同意に基づき、転職、就職、副業、フリーランス案件、社内異動、プロジェクトアサインなどに利用できる「実績パスポート」として共有できる。

## 2. ビジョン

働いた実績と貢献が、所属企業や肩書に依存せず、正しく記録・評価される社会をつくる。

現在の人事評価や採用選考では、履歴書、職務経歴書、面接、上司の主観などが大きな判断材料となっている。

しかし、それらの情報だけでは、候補者が実際にどのような仕事を担当し、チームの中でどのように行動し、どれほど貢献したのかを正確に把握することは難しい。

Vallogは、日々の業務データを継続的に記録することで、後から作られた自己申告ではなく、実際の行動に基づく評価材料を提供する。

## 3. ミッション

仕事の過程と貢献を客観データで可視化し、人事評価、採用、報酬、キャリア形成における納得感を高める。

Vallogが評価そのものを決定するのではなく、評価を行うための根拠を提供する。

最終的な判断は企業、チーム、本人が行い、Vallogは透明性の高い合意形成を支援するインフラとして機能する。

## 4. 解決する課題

### 4-1. 企業の人事評価における課題

企業の人事評価では、以下のような問題が発生しやすい。

- 上司の印象や主観に評価が左右される
- 目立つ成果だけが評価され、レビューや支援業務が見落とされる
- プロジェクトを横断した貢献を把握しにくい
- 評価面談の際に客観的な根拠が不足する
- リモートワークでは勤務実態や貢献が見えにくい
- エンジニアの仕事を人事担当者が正しく理解しにくい
- 作業量と成果の質が混同される

**Vallogの解決策**  
GitHub上のIssue、Pull Request、レビュー、コミット、対応速度などを整理し、人事評価の補助資料として提供する。

### 4-2. 採用における課題

採用企業は、履歴書や面接だけでは候補者の実務能力を十分に判断できない。

特にエンジニア採用では、以下の情報を確認することが難しい。

- 実際にどのような機能を開発したのか
- チーム内でどの役割を担っていたのか
- コードレビューやメンバー支援を行っていたか
- 課題を自ら発見して解決できるか
- 継続的に仕事を進められるか
- 他のメンバーと協力して開発できるか
- 自己申告された経験と実態が一致しているか

**Vallogの解決策**  
実績パスポートを利用することで、企業は候補者の自己申告だけでなく、根拠リンクと時系列データを参考に選考できる。これにより、採用判断の精度を高め、入社後のミスマッチを減らす。

### 4-3. 個人のキャリアにおける課題

個人が転職や副業に挑戦する際、過去の仕事を客観的に証明する方法は限られている。

GitHubリポジトリをそのまま共有しても、採用担当者が大量のIssueやPull Requestを確認することは難しい。

また、企業内で行った仕事は本人の実績であっても、退職後には確認しにくくなる場合がある。

**Vallogの解決策**  
本人が閲覧を許可された範囲のデータを整理し、持ち運び可能な実績として蓄積する。

## 5. 提供する価値

### 企業への価値

- 人事評価に利用できる客観的な補助データ
- 評価面談の根拠となる時系列の業務記録
- エンジニアの仕事内容を人事担当者にも分かりやすく可視化
- 採用候補者の実務経験を確認できる
- 採用後の配属やプロジェクトアサインの参考になる
- 業務委託や副業人材の選定にも利用できる
- 評価に対する従業員の納得感を高められる

### 個人への価値

- 自分が担当した仕事を継続的に記録できる
- 転職時に実績を根拠付きで証明できる
- 新卒採用やインターン応募に利用できる
- 副業、業務委託、フリーランス営業に利用できる
- 社内異動や昇進面談の資料として使える
- 自身の成長や得意分野を把握できる
- 所属企業が変わってもキャリアデータを持ち運べる

### チームへの価値

- 個人ごとの貢献を可視化できる
- 貢献の偏りや属人化を発見できる
- 振り返りや報酬分配の根拠を作れる
- 目立ちにくいレビューや支援業務も記録できる
- プロジェクト終了後に各メンバーの実績を残せる

## 6. プロダクト構成

Vallogは、利用目的に応じて3つのサービスで構成する。

### 6-1. Vallog Team

有志開発、学生チーム、副業チーム、ハッカソン、社内開発チーム向けの貢献可視化サービス。

**主な機能**

- GitHub連携
- Issue、Pull Request、レビュー、コミットの取得
- メンバー別の活動量表示
- カテゴリ別の貢献表示
- 対応速度やレビュー実績の表示
- プロジェクト別ダッシュボード
- チーム内での評価コメント
- 重みを変更できる分配シミュレーション
- 編集履歴と評価根拠の保存

### 6-2. Vallog Work Passport

個人が自身の仕事と貢献を蓄積し、必要な相手へ共有できる実績パスポート。

**パスポート掲載情報**

- 参加したプロジェクト
- プロジェクトの期間
- 担当した領域
- 完了したIssue
- 作成・対応したPull Request
- コードレビュー実績
- プロジェクト内での役割
- 継続的な活動状況
- GitHub上の根拠リンク
- メンバーや管理者による確認履歴
- AIによって整理された貢献サマリー
- 情報の作成日時と更新履歴

本人は、共有する項目、共有相手、公開期間を設定できる。企業保有の非公開情報は、企業側と本人の双方の設定を満たした範囲のみ表示。

### 6-3. Vallog Business

法人向けの人事評価、採用、配置、育成支援サービス。

**主な機能**

- 複数チームの一括管理
- メンバーごとの業務実績表示
- プロジェクト横断での貢献確認
- 評価期間の設定
- 人事評価用レポート
- 評価コメントと承認フロー
- 管理者権限
- 編集・閲覧の監査ログ
- CSV・PDF出力
- 社内異動やアサイン候補の検索
- 候補者から共有されたWork Passportの閲覧
- 複数候補者の比較
- 面接で確認すべき項目の整理
- 将来的な人事システム、ATS、Slackとの連携

## 7. 可視化するデータ

Vallogでは、単純なコミット数だけで人を評価しない。複数の指標を分けて表示する。

### 開発量

- 完了Issue数
- Pull Request数
- コミット数
- 担当したStory Point
- 変更ファイル数
- 対応した機能領域

### 開発プロセス

- Issue着手から完了までの時間
- Pull Request作成からマージまでの時間
- 修正対応回数
- 継続的な活動日数
- 期限内の対応率

### チーム貢献

- コードレビュー数
- 他メンバーへのコメント
- Issueの作成・整理
- バグ報告
- ドキュメント作成
- 他メンバーの作業を前進させた活動

### 定性的な貢献

- 担当した機能の概要
- 解決した課題
- 技術的な工夫
- プロジェクトに与えた影響
- チームメンバーや管理者のコメント

それぞれの数値は評価の材料として提示し、優劣の自動判定は行わない。

## 8. AIの利用方針

Vallogでは、AIが人事評価、採用可否、報酬分配を自動決定しない。AIの用途は**GitHub上の大量の活動データを人間が理解しやすい形に整理すること**に限定する。

### AIを利用する機能

- コミット内容の要約
- Pull Requestの要約
- 担当機能の整理
- プロジェクト期間中の貢献サマリー生成
- 面接時に確認すべき項目の抽出
- 評価面談用の振り返り文章の下書き

### AIを利用しない領域

- 個人の優劣の自動判定
- 採用・不採用の決定
- 人事評価ランクの決定
- 給与や報酬額の決定
- チーム内の分配割合の最終決定

## 9. 人事評価での利用方法

想定する利用フロー：

1. GitHub組織とVallogを連携する
2. 評価対象となるチームと期間を設定する
3. メンバーごとの業務データを取得する
4. AIが活動内容を分かりやすく要約する
5. 本人が内容を確認し、補足情報を入力する
6. 上司やチームメンバーがコメントを追加する
7. 人事担当者が評価面談の資料として利用する
8. 最終的な評価は企業が決定する
9. 本人に共有可能な実績をWork Passportへ保存する

## 10. 採用での利用方法

求職者はWork Passportから共有情報を選択し、期間限定の閲覧URLを発行。  
採用企業は同意を得た範囲で詳細な実務情報を確認できる。

Vallogは職務経歴書・面接・技術試験などと**組み合わせ**て利用する。

## 11. 転職以外の利用場面

- 社内の人事評価・昇進面談
- 社内異動・新規プロジェクトアサイン
- インターン・新卒採用
- 副業・業務委託・フリーランス営業
- ハッカソン・学校での成果発表
- 1on1やキャリア面談 など

## 14. 競争優位性

- **日常利用によるデータ蓄積**：プロジェクト期間中から自然にデータが蓄積
- **根拠データへの移動**：表示からGitHubの元データへ直接リンク
- **AIに判断を委ねない**：透明性の高い根拠提供
- **個人の実績持ち運び**：企業を超えたキャリアデータ基盤
- **作業量だけでなくチーム貢献**：レビュー・支援業務なども評価対象

## 17. 重要KPI

- 登録チーム数 / 月間アクティブチーム数
- Work Passport作成者数 / 企業への共有件数
- 有料法人契約数 / 月間経常収益
- Communityから法人契約への転換数 など

## 18. リスクと対応方針

- 数字だけで評価されるリスク → 複数指標の表示、人間による最終判断
- 非公開情報漏洩リスク → 二重の公開設定
- AI要約の誤り → 確認・修正機能と元データリンク
- 過度な利用リスク → ガイドラインの明記と総合評価の推奨

## 19. 将来的な事業展開

エンジニア向けGitHub連携から開始し、デザイナー（Figma）、プロジェクトマネージャー（Jira/Notion）、営業（CRM）など**さまざまな職種**へ拡大。

最終目標：所属企業や雇用形態に依存しない「仕事の信用インフラ」としてのワークパスポートの実現。

## 20. Vallogが目指す姿

Vallogは、社員を監視するためのツールでも、AIが人間の価値を判定するサービスでもありません。

**本人・チーム・企業が同じ事実を確認し、納得感のある評価・採用・報酬・キャリア形成を行うための共通基盤**です。

日々の仕事を記録し、人事評価に活用し、その実績を本人のキャリアとして持ち運べる——  
Vallogは、仕事の実績と信頼を可視化する「ワークパスポート」を提供します。
